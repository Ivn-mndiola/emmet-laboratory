Learning Notes

Semantic HTML explains the purpose of each part of a page.

  • header introduces a page or section.
  • nav groups navigation links.
  • main holds the main content.
  • section groups related content.
  • article holds a self-contained item.
  • aside adds related information.
  • footer holds closing information.

Complex Emmet Example

This abbreviation creates a container, a header, a heading, a paragraph, and a navigation menu with four links.

div.container>header>h1{My Portfolio}+p{Web Developer}+nav>ul>li*4>a{Menu $}

The navigation is inside the header because + keeps it at the heading and paragraph level.
