About This Exercise

I am practicing how to add classes and IDs to HTML elements using Emmet.

A container with an ID

An ID identifies one element. A class can be used on several elements.

Featured Card

This element has two classes: card and featured.

Abbreviations Used

  • header.site-header adds a class.
  • nav#main-nav adds an ID.
  • main.content adds a class to the main content.
  • section#about.content-section combines an ID and a class.
  • div.card.featured adds multiple classes.
  • footer.site-footer adds a footer class.
